# Unitree电机驱动使用说明

## 概述

本驱动为Unitree GO-M8010-6关节电机提供了高层控制接口，基于RS485通信协议。驱动架构参考了大疆电机（DJ_Motor）和DM电机（DM_Motor_Fdcan）的设计模式，提供统一的API接口。

## 文件结构

```
USER/Module/UNITREE_Motor_485/
├── 485driver/              # 底层485通信驱动（已提供）
│   ├── GO-M8010-6.c
│   ├── motor_control.h
│   ├── crc_ccitt.h
│   └── ris_protocol.h
└── USER_Driver/            # 高层电机驱动
    ├── unitree_motor.h     # 驱动头文件
    ├── unitree_motor.c     # 驱动实现文件
    └── 使用说明.md         # 本文档
```

## 主要特性

- ✅ 支持多电机管理（最多8个）
- ✅ 统一的注册和控制接口
- ✅ FOC闭环控制模式
- ✅ 位置、速度、扭矩混合控制
- ✅ 可配置的刚度（Kp）和阻尼（Kd）系数
- ✅ 实时反馈数据解析
- ✅ 通信错误统计
- ✅ 调试信息打印功能

## 快速开始

### 1. 包含头文件

```c
#include "unitree_motor.h"
```

### 2. 电机注册

```c
// 定义电机配置
unitree_motor_config_t motor_config = {
    .motor_id = 0x01,              // 电机ID (0-14)
    .channel = usart2_485,         // 通信通道 (usart2_485 或 usart3_485)
    .mode = UNITREE_MODE_FOC,      // 工作模式：FOC闭环控制
};

// 注册电机（不使用回调函数）
unitree_motor_object_t *motor1 = unitree_motor_register(&motor_config, NULL);

// 或者注册电机并指定控制回调函数
unitree_motor_object_t *motor2 = unitree_motor_register(&motor_config, motor_control_callback);
```

### 3. 使能电机

```c
// 使能电机（进入FOC控制模式）
unitree_motor_enable(motor1);
```

### 4. 设置控制参数

```c
// 设置电机控制参数
// 参数：位置(rad), 速度(rad/s), 扭矩(N.m), Kp(刚度), Kd(阻尼)
unitree_motor_set_control(motor1, 
                         0.0f,    // 目标位置: 0 rad
                         0.0f,    // 目标速度: 0 rad/s
                         0.5f,    // 目标扭矩: 0.5 N.m
                         10.0f,   // Kp: 10.0 (刚度系数, 范围0-25.6)
                         1.0f);   // Kd: 1.0 (阻尼系数, 范围0-25.6)
```

### 5. 周期性控制任务

在RTOS任务或定时器中周期性调用控制函数（建议频率500-1000Hz）：

```c
void Motor_Task(void *argument)
{
    for(;;)
    {
        // 统一控制所有已注册的电机
        unitree_motor_control();
        
        osDelay(1);  // 1ms周期 = 1000Hz
    }
}
```

### 6. 读取反馈数据

```c
// 读取电机位置
float position = motor1->measure.position;

// 读取电机速度
float velocity = motor1->measure.velocity;

// 读取电机扭矩
float torque = motor1->measure.torque;

// 读取电机温度
int8_t temperature = motor1->measure.temperature;

// 读取错误码
uint8_t error = motor1->measure.error;
```

### 7. 失能电机

```c
// 失能电机（进入IDLE模式，控制参数清零）
unitree_motor_disable(motor1);
```

## 完整示例

### 示例1：简单位置控制

```c
#include "unitree_motor.h"

unitree_motor_object_t *motor1;

void unitree_motor_init_task(void)
{
    // 1. 配置电机
    unitree_motor_config_t config = {
        .motor_id = 0x01,
        .channel = usart2_485,
        .mode = UNITREE_MODE_FOC,
    };
    
    // 2. 注册电机
    motor1 = unitree_motor_register(&config, NULL);
    
    // 3. 使能电机
    unitree_motor_enable(motor1);
    
    // 4. 设置初始位置
    unitree_motor_set_control(motor1, 0.0f, 0.0f, 0.0f, 20.0f, 1.5f);
}

void Motor_Control_Task(void *argument)
{
    float target_pos = 0.0f;
    
    for(;;)
    {
        // 周期性改变目标位置（正弦波）
        target_pos = 1.57f * sin(HAL_GetTick() / 1000.0f);  // ±90°
        
        // 更新控制参数
        unitree_motor_set_control(motor1, target_pos, 0.0f, 0.0f, 20.0f, 1.5f);
        
        // 发送控制指令
        unitree_motor_control();
        
        osDelay(1);  // 1ms
    }
}
```

### 示例2：使用控制回调函数

```c
#include "unitree_motor.h"

unitree_motor_object_t *motor1;

// 自定义控制回调函数
void motor1_control_callback(unitree_motor_object_t *motor)
{
    // 在此处实现自定义控制逻辑
    // 例如：基于传感器反馈的闭环控制
    
    float current_pos = motor->measure.position;
    float target_pos = 0.0f;  // 从其他地方获取目标位置
    
    // 简单的位置控制
    float error = target_pos - current_pos;
    float torque = 0.5f * error;  // 简单P控制
    
    // 限制扭矩范围
    if (torque > 10.0f) torque = 10.0f;
    if (torque < -10.0f) torque = -10.0f;
    
    // 更新控制参数
    unitree_motor_set_control(motor, target_pos, 0.0f, torque, 15.0f, 1.0f);
}

void unitree_motor_init_task(void)
{
    unitree_motor_config_t config = {
        .motor_id = 0x01,
        .channel = usart2_485,
        .mode = UNITREE_MODE_FOC,
    };
    
    // 注册电机时传入回调函数
    motor1 = unitree_motor_register(&config, motor1_control_callback);
    
    unitree_motor_enable(motor1);
}

void Motor_Control_Task(void *argument)
{
    for(;;)
    {
        // 控制函数会自动调用回调函数
        unitree_motor_control();
        
        osDelay(1);
    }
}
```

### 示例3：多电机控制

```c
#include "unitree_motor.h"

#define MOTOR_NUM 4

unitree_motor_object_t *motors[MOTOR_NUM];

void unitree_motors_init(void)
{
    // 初始化4个电机
    for (int i = 0; i < MOTOR_NUM; i++)
    {
        unitree_motor_config_t config = {
            .motor_id = i + 1,       // ID: 1, 2, 3, 4
            .channel = usart2_485,
            .mode = UNITREE_MODE_FOC,
        };
        
        motors[i] = unitree_motor_register(&config, NULL);
        unitree_motor_enable(motors[i]);
    }
}

void Motor_Control_Task(void *argument)
{
    for(;;)
    {
        // 为每个电机设置不同的控制参数
        for (int i = 0; i < MOTOR_NUM; i++)
        {
            float pos = 1.0f * sin(HAL_GetTick() / 1000.0f + i * 1.57f);
            unitree_motor_set_control(motors[i], pos, 0.0f, 0.0f, 15.0f, 1.0f);
        }
        
        // 统一发送控制指令
        unitree_motor_control();
        
        osDelay(2);  // 500Hz
    }
}
```

## API参考

### 数据结构

#### `unitree_motor_config_t`
电机配置结构体
```c
typedef struct {
    uint8_t motor_id;           // 电机ID (0-14, 15为广播)
    Channel_t channel;          // 通信通道
    unitree_mode_e mode;        // 工作模式
} unitree_motor_config_t;
```

#### `unitree_motor_measure_t`
电机反馈数据结构体
```c
typedef struct {
    uint8_t motor_id;           // 电机ID
    uint8_t mode;               // 当前工作模式
    int8_t temperature;         // 电机温度 (°C)
    uint8_t error;              // 错误码
    float position;             // 当前位置 (rad)
    float velocity;             // 当前速度 (rad/s)
    float torque;               // 当前扭矩 (N.m)
    float foot_force;           // 足端传感器数据
    // ... 其他字段
} unitree_motor_measure_t;
```

### 主要函数

| 函数名 | 说明 | 参数 | 返回值 |
|--------|------|------|--------|
| `unitree_motor_register()` | 注册电机实例 | config, callback | 电机对象指针 |
| `unitree_motor_enable()` | 使能电机 | motor | 无 |
| `unitree_motor_disable()` | 失能电机 | motor | 无 |
| `unitree_motor_set_control()` | 设置控制参数 | motor, pos, vel, tor, kp, kd | 无 |
| `unitree_motor_control()` | 周期性控制函数 | 无 | 无 |
| `unitree_motor_send()` | 立即发送指令 | motor | 0成功 -1失败 |
| `unitree_motor_clear_ctrl()` | 清除控制参数 | motor | 无 |
| `unitree_motor_get_by_id()` | 根据ID获取电机 | motor_id, channel | 电机对象指针 |
| `unitree_motor_print_info()` | 打印电机信息 | motor | 无 |

## 参数说明

### 位置 (Position)
- 单位：rad（弧度）
- 范围：根据电机型号，通常±411774 rad

### 速度 (Velocity)
- 单位：rad/s（弧度/秒）
- 范围：-804.0 ~ 804.0 rad/s

### 扭矩 (Torque)
- 单位：N.m（牛·米）
- 范围：-127.99 ~ 127.99 N.m

### 刚度系数 Kp
- 范围：0 ~ 25.6
- 说明：位置控制刚度，越大响应越快，但可能引起震荡

### 阻尼系数 Kd
- 范围：0 ~ 25.6
- 说明：速度阻尼，用于抑制震荡

### 控制方程
```
实际扭矩 = Kp × (目标位置 - 当前位置) + Kd × (目标速度 - 当前速度) + 前馈扭矩
```

## 错误码说明

| 错误码 | 说明 |
|--------|------|
| 0 | 正常 |
| 1 | 电机过热 |
| 2 | 电机过流 |
| 3 | 电机过压 |
| 4 | 编码器故障 |
| 5-7 | 保留 |

## 注意事项

1. **通信频率**：建议控制频率为500-1000Hz，过高可能导致通信拥塞
2. **参数范围**：设置参数时注意范围限制，底层驱动会自动饱和处理
3. **使能顺序**：必须先注册电机，再使能电机，最后才能控制
4. **多电机时序**：使用`unitree_motor_control()`可确保所有电机按顺序通信
5. **错误处理**：定期检查`measure.error_cnt`，通信错误过多时需检查硬件连接
6. **温度监控**：持续监控电机温度，超过80°C应降低负载或停止运行

## 常见问题

### Q1: 电机不响应？
- 检查RS485硬件连接
- 确认电机ID和通道配置正确
- 确认电机已使能 `unitree_motor_enable()`

### Q2: 通信错误率高？
- 降低控制频率
- 检查RS485总线终端电阻
- 检查DE/RE引脚控制时序

### Q3: 电机抖动？
- 降低Kp值
- 增加Kd值
- 检查机械负载是否过大

### Q4: 如何实现力控？
```c
// 纯力矩控制：Kp=0, Kd=0
unitree_motor_set_control(motor1, 0.0f, 0.0f, 5.0f, 0.0f, 0.0f);
```

### Q5: 如何实现阻抗控制？
```c
// 设置合适的Kp和Kd实现柔顺控制
unitree_motor_set_control(motor1, target_pos, 0.0f, 0.0f, 5.0f, 0.5f);
```
